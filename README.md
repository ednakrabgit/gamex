# 🎮 QuizQuest - ระบบเว็บเกมทำข้อสอบออนไลน์ (Online Exam & Game Platform)

เว็บแอปพลิเคชันเกมทำข้อสอบออนไลน์ที่ทันสมัย สวยงาม เล่นสนุก ดึงดูดความสนใจ พร้อมระบบตรวจข้อสอบจริง เฉลยละเอียดทุกข้อ และออกใบประกาศนียบัตรเกียรติคุณ (Certificate)

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 🗺️ **คลังข้อสอบ 50 ชุดวิชา (ครบถ้วนทุกหมวด)**: ครอบคลุมวิชาคณิตศาสตร์, ภาษาไทย, วิทยาศาสตร์, ภาษาอังกฤษ, สังคมศึกษา, ประวัติศาสตร์, ดรุณศึกษา, สุขศึกษา, การงานอาชีพ, นาฏศิลป์ (ปลดล็อกให้เลือกเล่นได้อิสระทุกชุด)
- 👾 **โหมดศึกสู้บอส (Boss Battle)**: ตอบคำถามสะสมคอมโบ 🔥 เพื่อลดพลังชีวิตของบอสประจำวิชา
- 📝 **โหมดจำลองสอบปลายภาคเสมือนจริง (Exam Simulation)**: คละข้อสอบจากทุกวิชา จับเวลารวม และตัดเกรด A-F (เกรด 4.0 ถึง 0.0) พร้อมการประเมินผล
- ⚡ **โหมดท้าประลองคิดเร็ว (Speed Rush)**: ตอบคำถามให้ได้มากที่สุดใน 60 วินาที ตอบถูกเพิ่มเวลา
- 🔊 **ระบบเสียง & Thai Text-to-Speech**:
  - เสียงเอฟเฟกต์สะใจด้วย Web Audio API (ไม่ต้องต่อเน็ต ไม่ต้องโหลดไฟล์เพิ่ม)
  - ปุ่ม 🔊 กดฟังเสียงอ่านโจทย์และตัวเลือกภาษาไทย เหมาะสำหรับเด็ก ป.1 และผู้เรียนทุกวัย
- 💡 **ไอเทมตัวช่วย (Lifelines)**: 50:50 (ตัด 2 ตัวเลือกที่ผิด), Freeze (หยุดเวลา 10 วินาที), Hint (คำใบ้แนวคิด), Shield (เกราะป้องกัน)
- 📊 **ระบบตรวจข้อสอบ & เฉลยละเอียด (Solutions)**: แสดงคำตอบที่เลือกเทียบกับเฉลย พร้อมคำอธิบายหลักการเหตุผลทุกข้อ
- 📜 **ใบประกาศนียบัตร (Certificate of Achievement)**: ออกใบเกียรติบัตรพร้อมชื่อผู้สอบ เกรดที่ได้ และตราประทับสีทอง สามารถสั่งพิมพ์หรือบันทึกเป็น PDF ได้ทันที
- ✏️ **Custom Quiz Studio**: สามารถสร้าง แก้ไข หรือนำเข้า/ส่งออกข้อสอบของตนเองได้

## 🚀 วิธีเปิดใช้งาน (Getting Started)

### 1. ใช้งานผ่าน GitHub Pages (เล่นออนไลน์ได้ทันที)
1. ไปที่เมนู **Settings** ของ Repository บน GitHub
2. ไปที่หัวข้อ **Pages** (แถบเมนูด้านซ้าย)
3. ภายใต้ **Build and deployment > Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. เว็บไซต์จะเปิดให้เข้าเล่นได้ทันทีผ่านลิงก์ของ GitHub Pages

### 2. เปิดใช้งานบนเครื่อง (Local)
สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge, Firefox, Safari) หรือเปิดผ่าน Local Web Server:
```bash
python -m http.server 8080
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`
